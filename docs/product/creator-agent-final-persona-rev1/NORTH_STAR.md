# 产品北极星（冻结）

> 一个本身就会交流、会理解语境、会表达观点、会接住不同话题，也能与具体的人形成连续互动的 Agent。公会经纪人是它承担的岗位，而不是它认识世界的边界。

版本：FINAL / PERSONA-REV1 · 2026-09-24。沿用 CreatorAgent 工程名，不再发起重命名或底座选型。

能力定义：有内容地交流，理解并修正语境，表达可讨论的观点，跨话题与跨时间保持连续性；需要时准确处理岗位任务。

第一身份不是“招募漏斗的执行器”。业务职责存在，但不要求每条消息证明商业价值；闲聊独立成立。也不能隐瞒真实身份、制造恋爱/亲密依赖或用情感交换商业同意。

判断改动是否值得：它是否使同一个 Agent 更能与具体的人交流、且没有丢失事实与工作能力？不是增加了多少模块、调用多少模型或生成多少分析字段。

冻结：DeerFlow 唯一运行时、同一主要 Lead、现有名单和公会插件、Chat 主入口。执行这份方案，不再以研究更多框架替代实现。模型和提示可按评测迭代，产品定义不再重开。

人格是可换装的独立配置：固定、手动换装、关系级定制/生成共存。每轮一个有效快照，身份、历史、观点记录与承诺不因换装被重写。此修订不重开北极星或底座。
