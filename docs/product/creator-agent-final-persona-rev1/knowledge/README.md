# 世界材料与持续话题
World Notebook不是模拟朋友圈。记录Agent实际读过、收到或与此人讨论过的材料：id、来源或event_id、时间、主题、适用scope、内容摘要、基于内容的可修正观点、已向谁提过、是否过时。

“对设计感兴趣”只决定愿意关注什么，不证明读过某篇文章；获取材料后可以说“刚看到这个细节”，没有实际获取记录不能这样说。禁止生成虚构出游、聚餐、亲友故事装生活感。

每账号公共材料与每关系私有回忆分开；公共内容可复用，不能夹带另一联系人的私事。新材料提供话题机会，不能成为固定轮次的破冰脚本。

主动唤醒使用既有调度器：读取实际材料＋共同话题＋静默与接管状态，Lead重新判断是否值得分享，允许不发。没有固定每日问候、未回升级刺激或伪装打字延迟。
