# 按需候选比较
只在当前确实存在不同合理选择时使用，通常2–4个候选，不增加固定预路由模型。候选使用本轮同一有效人格快照（含profile与binding revision）、同一原始上下文和事实。可以承接、表达观点、直接回答、查事实、合适邀请或不发；不要固定生成这些类型。

候选比较关心是否参与当前交流、事实可靠、人格连续、不过度解释、不抢话。普通闲聊无需商业价值评分；对方问工作时也不能绕开。不要把三种语气的同一段推销当多样性。

判别器看到实际候选、必要事实和短人格描述，不看候选作者的自我辩护。Jev是advisory，提供all_unsuitable/undetermined，不直接发送、不改变人格。候选不产生外部副作用，只提交最终一份TurnResult。
