## 不再重开的决定

一个DeerFlow运行时、同一主要Lead；名单来源与公会后台插件已完成，查真实接口并复用。产品先是会交流的Agent，公会经纪人是岗位不是世界边界。Chat是管理入口，不重做CRM。

人格是独立可换装资产，不与子Agent一一绑定。必须同时支持：固定绑定账号或已有Agent/子Agent、手动更换、关系级定制、根据实际沟通偏好/管理要求生成新profile。六模板只作起始库，账号默认基于relaxed_wit@1.0.1。解析顺序为账号默认→Agent/子Agent覆盖→关系覆盖→本轮临时表达适配，最后只获得一份有效persona快照。

换装不重写真实身份、经历、关系事实、已发表观点记录、承诺和权限。可以更换完整风格，不要继续保留“联系人只能调语气不能换人格”的旧限制。自然交流不依赖伪装身份，也不针对性别、收入、职业标签或脆弱性自动配型。
